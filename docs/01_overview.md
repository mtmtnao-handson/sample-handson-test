# 概要

このページでは、サンプルハンズオンの概要について説明します。

---

## 背景

このサンプルは、aws-handson-portal のポータルカード自動登録機能をテストするために作成されました。

各ハンズオンリポジトリが `handson-meta.json` を S3 にアップロードすると、ポータルが自動的にスキャンしてカードを生成します。

---

## テスト内容

1. テンプレートリポジトリから新規リポジトリを作成
2. `handson-meta.json` と `mkdocs.yml` を編集
3. GitHub にプッシュしてデプロイ
4. ポータルサイトでカードが表示されることを確認
